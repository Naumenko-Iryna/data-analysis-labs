# Лабораторні роботи №9–12 (Варіант 12)
Інтерактивний вебдодаток на базі **Streamlit** для виконання лабораторних робіт №9–12 з курсу «Інструментальні засоби аналізу даних»

## Вміст:
- **Лабораторна робота №9:** Обробка даних за допомогою `pandas` та `statistics` (розрахунок зарплат адвокатів).
- **Лабораторна робота №10:** Імпорт та візуалізація даних із MS Excel (фірма паркової архітектури).
- **Лабораторна робота №11:** Аналіз даних пасажирів Titanic та часових рядів акцій Apple.
- **Лабораторна робота №12:** Візуалізація кластерного аналізу методом `Clustergram` (K-Means, GMM, PCA).
